# boring-junie-extension

Junie CLI marketplace repository with a single extension: **skill-creator**.

## Extensions

| Extension | Description |
| --- | --- |
| [skill-creator](./extensions/skill-creator) | Guide and helpers for creating effective Junie agent skills |

## Install

1. Open Junie and run `/extensions` (aliases: `/plugin`, `/plugins`).
2. Add this repo as a marketplace, for example:
   - `BrayanCaro/boring-junie-extension`
   - `https://github.com/BrayanCaro/boring-junie-extension`
3. Install **skill-creator** at project or user scope.

Marketplace manifest: [`.junie-extension/marketplace.json`](./.junie-extension/marketplace.json).

Layout follows the [JetBrains junie-extensions](https://github.com/JetBrains/junie-extensions) conventions and [Junie CLI extensions docs](https://junie.jetbrains.com/docs/junie-cli-extensions.html).
